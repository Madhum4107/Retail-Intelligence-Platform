# Retail AI Intelligence Platform

An AI-powered retail analytics dashboard built using Python, Pandas, Scikit-Learn and Streamlit.

## Features

* Interactive Dashboard
* Sales Analytics
* Inventory Monitoring
* Demand Forecast Insights
* Business KPI Dashboard
* Category & Region Filters
* CSV Report Download

## Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Streamlit
* Scikit-Learn

## Dataset

Retail Store Inventory Dataset

## How to Run

pip install -r requirements.txt

streamlit run dashboard/app.py
